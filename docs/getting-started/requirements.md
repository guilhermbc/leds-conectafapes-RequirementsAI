# Requirements

Before running Requirement AssIstant (RAI), make sure your environment meets the following requirements.

## Mandatory Requirements

The following dependencies are required regardless of the execution method:

* Python 3.12 or higher
* A valid Gemini API key (`GEMINI_API_KEY`)

## Local Execution

For local execution, you will also need:

* Git
* `pip` or Poetry

## Docker Execution

If you prefer running the project with Docker, install:

* Docker Engine 24+
* Docker Compose

## Supported Operating Systems

RequirementsAI has been tested on:

* Windows 10/11
* Linux

## Network Requirements

An internet connection is required to:

* Access Gemini models through the Gemini API
* Download project dependencies
* Pull Docker images (Docker execution only)
