## Dúvidas e Validações Pendentes

As seguintes questões precisam ser respondidas pelos stakeholders para finalizar o detalhamento e confirmar o escopo:

1.  **Escopo de RF016/RN012 (Novas Propostas):** Confirmar se a funcionalidade de submeter novas propostas **estará** no escopo deste portal. Se sim, a prioridade deve ser reavaliada (provavelmente para Alta). Se não, remover/marcar como "Fora de Escopo".
2.  **Papéis Adicionais (Pesquisador/Empreendedor - Q2):** Quais *ações específicas* (funcionalidades/permissões) estes papéis teriam *dentro deste portal*? Apenas visualização ou ações como Coordenadores/Bolsistas? Isso impacta RN013.
3.  **Fluxo Implementação/Remanejamento (Q3, Q4):**
    *   Quais dados específicos são enviados do Portal para o Admin na solicitação (RF010)?
    *   Como o Portal é notificado da mudança de status vinda do Admin (RF018)? (API, consulta periódica?)
    *   Existem diferentes *tipos* de remanejamento com regras distintas?
    *   Como as restrições orçamentárias (RF013) são aplicadas na simulação (RF011) e solicitação (RF010)?
4.  **Validação de Documentos (Q5):** Se a validação ocorre no Admin, como o *motivo* de rejeição/pendência é comunicado de volta ao Portal para exibição ao usuário (RF017)?
5.  **Edição de Dados do Bolsista (Q6):** Após o cadastro inicial (RF006), o Coordenador pode *editar* dados cadastrais do bolsista, ou apenas o próprio bolsista pode (via seu acesso)?
6.  **Detalhamento de Notificações (RF019):** Quais eventos *exatos* devem gerar notificações? Para quem? Por qual canal (e-mail, no portal)?
7.  **Detalhamento de Relatórios (RF020):** Quais relatórios *específicos* são essenciais para os Coordenadores na primeira versão? (Ex: Lista de bolsistas ativos, extrato de execução, documentos pendentes).
8.  **Política de Retenção de Dados (Q10):** Qual a política para retenção/expurgo de dados de projetos, participantes e documentos, considerando a LGPD (RNF003)? Aplica-se apenas a inativos ou também a dados antigos em projetos ativos?
9.  **Requisitos de Volume e Disponibilidade (Q9):** Qual o número esperado de usuários simultâneos, volume de dados (projetos, bolsistas, documentos) e qual o acordo de nível de serviço (SLA) esperado para disponibilidade (RNF005) e desempenho (RNF004)?
