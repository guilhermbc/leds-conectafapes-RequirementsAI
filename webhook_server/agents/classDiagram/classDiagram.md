# Agentes da Criação dos Diagramas de Classe

## Linha do Tempo dos Fluxos de Agentes

| Tempo | Requirements | Class Diagram                      |
|-------|--------------|------------------------------------|
| T1    | Transcrição  | Transcrição                        |
| T2    | Minimundo    | Minimundo                          |
| T3    | Análise      | Identificação de Classes           |
| T4    | Extração     | Extração do Diagrama de Classes    |
| T5    | Priorização  |                                    |
| T6    | Refinamento  |                                    |
| T7    |              | Revisão do Diagrama de Classes     |
| T8    |              | Refinamento do Diagrama de Classes |

---

## Agentes

### Transcrição
Converte o áudio da reunião em texto para documentar a criação do sistema.

---

### Minimundo
Gera uma descrição textual do minimundo do sistema, baseada na transcrição.

---

### Identificação de Classes
Analisa o minimundo para identificar as classes relevantes do sistema.

---

### Extração do Diagrama de Classes
Constrói o diagrama de classes com base nas classes identificadas.

---

### Revisão do Diagrama de Classes
Ajusta e corrige o diagrama considerando tanto a extração quanto o documento de requisitos.

---

### Refinamento do Diagrama de Classes
Realiza os ajustes finais e aprimora o diagrama de classes após a revisão.
