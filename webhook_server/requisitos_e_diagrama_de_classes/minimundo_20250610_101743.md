## Narrativa de Domínio: Portal FAPs

### 1. Nome do Sistema

O sistema em questão, inicialmente referido como "Portal do Coordenador", foi renomeado para **Portal FAPs**.

### 2. Propósito e Problemas a Resolver

O propósito principal do Portal FAPs é centralizar e otimizar a gestão de bolsas e projetos financiados pela FAPs, resolvendo problemas relacionados à burocracia e falta de visibilidade. Ele visa permitir que coordenadores e bolsistas gerenciem de forma autônoma e eficiente as informações de seus projetos e bolsas.

Os problemas específicos que o Portal FAPs deve resolver incluem:

*   **Implementação e Gestão de Bolsas:** Facilitar o processo de implementação de bolsas.
*   **Cadastro de Bolsistas e Coordenadores:** Simplificar o registro e a gestão de dados de bolsistas e coordenadores.
*   **Visibilidade de Projetos:** Permitir que o coordenador visualize informações cruciais de seu projeto, como:
    *   Bolsistas alocados.
    *   Recursos disponíveis (capital e custeio).
    *   Cotas de bolsa e sua duração.
*   **Remanejamento de Bolsas:** Oferecer a funcionalidade para que o coordenador possa realizar remanejamentos de bolsas, como a troca de uma bolsa de maior valor por duas de menor valor.

### 3. Processos e Atividades Principais

Para ser uma solução efetiva, o Portal FAPs deve apoiar os seguintes processos e atividades:

*   **Ajustes e Remanejamentos de Bolsas:** O sistema deve permitir que o próprio coordenador realize ajustes nas alocações de bolsas.
*   **Simulação de Remanejamentos:** Uma funcionalidade crucial é a capacidade de simular remanejamentos de bolsas. Isso permitirá ao coordenador prever como as alterações afetarão os valores e cotas das bolsas, e se haverá sobra de recursos, oferecendo maior previsibilidade antes de efetivar as mudanças.
*   **Cadastro e Gestão de Documentos:**
    *   Identificação clara dos documentos necessários para cada edital, tanto para o bolsista quanto para o coordenador.
    *   Reaproveitamento de documentos que não perdem a validade (ex: diploma) para evitar reenvios desnecessários.

### 4. Regras de Negócio e Restrições

Existem regras específicas que devem ser seguidas para a execução das atividades:

*   **Alocação de Bolsas por Projeto:** Cada projeto possui um conjunto específico de bolsas que podem ser alocadas.
*   **Requisitos de Bolsas FAPs:** Cada tipo de bolsa possui um conjunto de regras e níveis de exigência definidos pela FAPs.
*   **Elegibilidade do Bolsista:** A alocação de uma bolsa a uma pessoa não é arbitrária; o bolsista deve atender a requisitos específicos, que incluem:
    *   Certidões negativas (de diversas naturezas).
    *   Escolaridade mínima.
    *   Idade (maior de 18 anos, se não houver outra especificação).
    *   Formação e experiência relevantes.
*   **Residência no Estado:** Bolsistas, em geral, precisam residir no estado para receber a bolsa da FAPs.
*   **Autenticação:** O login no sistema deve ser realizado através do sistema de login do governo do Estado, que se integra com o SoulGov.

### 5. Entradas, Saídas e Dados Envolvidos

*   **Entradas:**
    *   **Informações do Bolsista:** Dados pessoais (nome, identidade, endereço), dados bancários, documentos comprobatórios (escolaridade, certidões, etc.).
    *   **Informações do Projeto/Edital:** Dados de alocação da FAPs, regras do edital (verba, como deve ser alocada, etc.).
*   **Saídas:**
    *   Visualização de bolsistas alocados, recursos, cotas e duração de bolsas.
    *   Resultados de simulações de remanejamento de bolsas (valores, cotas, recursos restantes).
    *   Status de documentos e processos de bolsa.
*   **Dados Envolvidos:**
    *   Dados de Bolsistas (pessoais, bancários, acadêmicos).
    *   Dados de Coordenadores.
    *   Dados de Projetos (orçamento, duração, status).
    *   Dados de Editais (regras, verbas, tipos de bolsa permitidos).
    *   Dados de Bolsas (tipo, valor, duração, requisitos).
    *   Documentos (comprovantes, certidões, diplomas).

### 6. Usuários e Papéis

O Portal FAPs é totalmente voltado para o público externo. Os principais papéis de usuário são:

*   **Pesquisadores:** Coordenadores de projetos.
*   **Bolsistas:** Indivíduos que recebem as bolsas.
*   **Empreendedores:** Pessoas envolvidas em programas de extensão, como o Centelha, que buscam empreender.

Esses usuários interagem com o sistema para cadastrar informações, visualizar dados de projetos e bolsas, realizar simulações e gerenciar documentos.

### 7. Integrações com Outros Sistemas/Módulos

O Portal FAPs se conecta a outros sistemas/módulos para obter e trocar informações:

*   **Sistema Administrativo (Admin):** Este sistema é responsável por alimentar o Portal FAPs com informações essenciais, como:
    *   Cadastro de editais.
    *   Aprovação de submissões de projetos (que podem ser feitas pelo portal, mas precisam de aprovação).
    *   Avaliações (ex: avaliação de Roque).
    *   Tipos de bolsas disponíveis.
    *   Existe uma base de dados preenchida por este sistema administrativo que é consumida pelo Portal FAPs.
*   **Sistema de Login do Governo do Estado (SoulGov):** Utilizado para a autenticação dos usuários.

### 8. Requisitos Não Funcionais (Restrições Adicionais)

*   **Desempenho:** Não foram definidos requisitos específicos de desempenho (tempo de resposta, volume de dados, número de usuários simultâneos) até o momento.
*   **Segurança:** A autenticação deve ser integrada com o sistema de login do governo do Estado (SoulGov).

### 9. Documentação e Referências Existentes

As seguintes fontes de informação devem ser consideradas no desenvolvimento:

*   **SIGFAPs:** Servirá como uma visão inicial e referência.
*   **Sistema Previamente Implementado:** Existe um sistema anterior com vasta documentação de análise que pode ser reutilizada.
*   **Resoluções da FAPs:** Documentos oficiais que detalham as regras e normativas.
*   **Reuniões e Entrevistas:** Conversas diretas com o pessoal da FAPs para levantamento de requisitos adicionais.

### 10. Sistemas Similares de Referência

A principal referência conhecida é o próprio **SIGFAPs**. Não há conhecimento de outros sistemas que operem no mesmo contexto específico de gestão de editais, bolsas, bolsistas e projetos.
