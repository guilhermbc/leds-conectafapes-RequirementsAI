## Perguntas e Validações

As prioridades e a estrutura dos requisitos estão bem definidas. As perguntas a seguir são cruciais para aprofundar o entendimento e refinar os detalhes para a fase de desenvolvimento.

1.  **Submissão de Projetos por Empreendedores:**
    *   Poderiam ser fornecidos requisitos mais detalhados para os "Empreendedores" em relação à submissão de projetos e suas funcionalidades de gestão de informações de projeto?
    *   Os "Coordenadores de Projeto" também submetem novos projetos via Portal FAPES, ou a submissão de projetos é exclusiva para "Empreendedores" (ex: no contexto do programa "Centelha")?

2.  **Fluxo de Trabalho de Implementação de Bolsas:**
    *   Qual é o fluxo de trabalho detalhado para a "implementação da bolsa" após o upload de documentos pelos Bolsistas? O Portal FAPES precisa suportar um processo de aprovação interno para a implementação da bolsa, ou isso é tratado inteiramente pelo sistema administrativo da FAPES?

3.  **Aprovação de Realocação de Bolsas:**
    *   As realocações de bolsas realizadas pelos coordenadores exigem uma etapa de aprovação (ex: por funcionários da FAPES via sistema administrativo) antes de se tornarem efetivas, ou são aplicadas automaticamente após a confirmação?

4.  **Regras de Gestão de Recursos (Capital/Custeio):**
    *   Existem regras ou restrições específicas para gerenciar e realocar recursos de "capital" e "custeio"? Os coordenadores podem realocar fundos entre essas duas categorias?

5.  **Tratamento de Erros e Validação:**
    *   Como o sistema deve lidar com casos em que um Bolsista não atende aos requisitos de elegibilidade (ex: idade, residência, formação) durante o registro ou alocação da bolsa?
    *   Quais regras de validação específicas se aplicam à entrada de dados (ex: formato de conta bancária, tipos de documentos, campos obrigatórios)?

6.  **Relatórios e Auditoria:**
    *   Existem requisitos de relatórios específicos para coordenadores (ex: resumos financeiros de projetos, relatórios de status de bolsas)?
    *   O sistema precisa manter um registro de auditoria das alterações feitas nos dados do projeto, alocações de bolsas ou recursos financeiros? Se sim, qual nível de detalhe é exigido?

7.  **Granularidade das Permissões de Usuário:**
    *   Quais são as permissões específicas para cada perfil de usuário (Coordenador, Bolsista, Empreendedor) além de suas funcionalidades primárias declaradas? Por exemplo, um Bolsista pode visualizar apenas os detalhes de sua própria bolsa, ou também algumas informações em nível de projeto?

8.  **Métricas de Desempenho:**
    *   Quais são as métricas de desempenho esperadas para o sistema, tais como: Tempos de resposta médios e máximos para operações chave (ex: carregamento de detalhes do projeto, execução de simulações)? Número esperado de usuários simultâneos? Volume esperado de dados (ex: número de projetos, Bolsistas, documentos) ao longo do tempo?

9.  **Acessibilidade:**
    *   Existem padrões de acessibilidade específicos (ex: níveis de conformidade WCAG) aos quais o Portal FAPES deve aderir?

10. **Retenção de Dados:**
    *   Quais são as políticas de retenção de dados para informações de usuários, dados de projetos e documentos carregados dentro do sistema?

As perguntas listadas acima são essenciais para aprofundar o detalhamento e garantir que todas as nuances do sistema sejam compreendidas antes do início do desenvolvimento. A obtenção das respostas a essas questões permitirá a criação de um conjunto de requisitos completo e acionável.
