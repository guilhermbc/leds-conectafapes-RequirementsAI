# Exemplo de Uso das Rotas (*Example of use of the routes*)
## Projeto
```json
{
  "nome": "projeto 1",
  "descricao": "descricao do projeto 1"
}
```

## Modulo
```json
{
  "nome": "modulo 1",
  "descricao": "descricao do modulo 1",
  "Projeto": 1
}
```

## Documento
### Minimundo
```json
{
  "versao": "1.0",
  "arquivo": "",
  "origemAudio": "AudioEntrevistaFelipe.mp3",
  "TipoDocumento": "MINIMUNDO",
  "DocumentoAnterior": null,
  "Modulo": 1,
  "DocumentoOrigem": []
}
```
